# SnapNet

A static HTML/CSS/JS single-page site that connects learners with qualified teachers and professional services from around the world.

This folder is the canonical copy of the site (the sibling `roundry 2/` folder is an earlier duplicate kept as reference; the wrapper folder must not be flattened).

## Features

- Home, About, My Profiles, Teachers, Contact, and "Add Me" sections
- Profile carousel (slide/cycle through profile cards with the "Next Profile" button)
- Contact form (client-side only)

## How to open

Double-click `index.html` in a browser, or serve the folder locally:

```console
python -m http.server 8000
```

Then visit http://localhost:8000.

> Profile photos reference local placeholders in `images/placeholder.svg`. Replace them with real photos as the project develops.
